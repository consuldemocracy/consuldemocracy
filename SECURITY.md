# Security policy

## Reporting a vulnerability

If you find a vulnerability in Consul Democracy, please send an email to security[AT]consuldemocracy.org.

We'd really appreciate it if you kept details about the vulnerability private. This way we can fix them, and institutions using Consul Democracy can upgrade before potential attackers learn how to take advantage of the vulnerability. So, please, do **not** open an issue on github to report vulnerabilities.

Thank you for helping us improve Consul Democracy!

## Disclosure process

We will fix the security vulnerability. Once we release a new version, we will publish security advisories, giving proper credit to the reporters (should it apply). In the release notes, we will reference these security advisories.

After three months, we will reveal the details about the vulnerability, and how malicious users could exploit it.

As usual, we recommend everyone to regularly update their Consul Democracy installations.
